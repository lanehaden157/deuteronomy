# Translation Choices

A working glossary of deliberate English renderings for this study's own
translation. **Starts from `canon-conventions.md`** (a vendored copy of `bible-core/canon/conventions.md`; don't edit it here): every row
there is this book's default too (y'all, Yahweh, sky/skies, slave, life/being,
look, chest, covenant, devote to destruction, inheritance, ḥesed untranslated,
…). This file records only what Deuteronomy decides for itself, including any
deviation from a canon default and the reason.

## How to use this file

Before rendering a word in a new unit, check here and in the canon conventions
and match a prior decision. If a different rendering fits better in one verse,
use it and flag the deviation; Lane decides whether it's a one-off or a
correction. A chat records a decision in the handoff's "Decisions"; Claude Code
updates the row and the Log. If a unit and this file disagree, flag it: the
unit is more likely right.

## Open question: Numeruswechsel (for Lane; nothing decided)

Moses switches between singular "you" (-ka) and plural "you" (-em) with no clear rule. Plural "you" is y'all by convention. Options for the singular:

1. **Plain "you" for singular, y'all for plural.** Shows every switch in the English; matches the canon rule and costs nothing. Risk: readers may over-read switches as meaning, when some are probably style.
2. **Mark the singular ("you, Israel" or "you (sg.)") at first occurrence in each speech, then plain "you".** Fewer interruptions, but the reader must remember which is which.
3. **Plain "you" and a flag (note or ◊) only at switches inside a single sentence or paragraph.** Keeps lines clean and flags the shifts that carry weight; needs a call on what counts.
4. **Singular rendered as "you yourself" or "each of you" when a collective address.** Reads naturally; adds words the Hebrew lacks and blurs sg./pl.
